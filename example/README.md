# Example: customized_country_phone_picker

Sample app demonstrating `CountryPhoneInput`, inline country prefix, bottom sheet and dialog pickers, and search field theming.

Run from repo root:

```bash
cd example && flutter run
```

Demo tabs: **Hero**, **Inline** (flag vs ISO code), **Dial Modes**, **Country Box**, **Phone Field**, **Picker**, **Themed Search**.

The example uses a path dependency on the parent package (`../`).
